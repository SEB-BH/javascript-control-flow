## About

In this module, you will learn how JavaScript **makes decisions** and **repeats actions**. You will compare values, write `if...else` statements, use `for` loops, and understand **truthy** and **falsy** values.

Each lesson uses short examples that you can run with Node.js.

## Content

| Lesson | Skills |
| --- | --- |
| [Setup](./setup/README.md) | Create an `app.js` file and run it with Node.js |
| [Concepts](./concepts/README.md) | Recognize sequence, branching, and looping |
| [Boolean Logic](./boolean-logic/README.md) | Compare values and combine conditions |
| [Branching](./branching/README.md) | Make decisions using `if`, `else if`, and `else` |
| [Looping](./looping/README.md) | Repeat code using a `for` loop |
| [Truthy and Falsy](./truthy-and-falsy/README.md) | Understand how JavaScript checks values in conditions |
